# flex 자동 수집 동의 문의

flex 서비스 이용약관 제8조 ⑨ 에 따라 플렉스 주식회사에 자동 수집 동의를 구하는 문의 내용이다.

**제목**: 구성원 본인 근무 일정의 자동 조회에 대한 동의 요청

안녕하세요. 오픈서베이에서 flex 를 사용하는 구성원 박현민입니다.

flex '내 근무' 에 등록된 제 근무 일정(근무, 재택근무, 외근, 휴가)을 개인 구글 캘린더에서 함께 보려고, 하루 한 번 제 일정을 조회해 ICS 파일로 만드는 개인 도구를 만들었습니다. flex 서비스 이용약관(2026-09-21 시행) 제8조 ⑨ 에 따라 자동화 수단으로 서비스에 접근해 정보를 가져오려면 회사의 동의가 필요하다고 이해하고 있어, 이 사용에 동의해 주실 수 있는지 여쭙고자 연락드립니다.

Open API 는 관리자가 발급하는 회사 단위 기능이라 구성원 개인이 쓸 수 없어서, 웹 앱이 부르는 API 를 그대로 부르는 방식으로 만들었습니다. 동작은 다음과 같습니다.

- 제 계정의 이메일과 비밀번호로, 웹 앱과 같은 순서로 로그인합니다.
- 근무 형태와 휴가 종류의 이름 목록, 그리고 지난 1년부터 오늘까지의 제 근무 일정을 한 달 단위로 조회합니다. 한 번 실행할 때 요청은 23건 정도이고, 하루에 한 번(오전 6시쯤) 실행합니다.
- 조회만 하며 근무나 휴가를 등록, 수정, 삭제하지 않습니다. 다른 구성원의 정보는 조회하지 않습니다.
- 실행은 GitHub Actions 에서 하고, 로그인 정보는 그 저장소의 암호화된 시크릿에 보관합니다. 만든 ICS 파일은 제 개인 도메인에 올려 구글 캘린더에서 구독합니다.
- 모든 요청의 User-Agent 에 도구 이름과 저장소 주소(flex2ics (+https://github.com/KENNYSOFT/flex2ics))를 밝히고 있고, 동작 전체는 이 공개 저장소에서 보실 수 있습니다.

매일 자동으로 실행하는 것은 동의를 받은 뒤에 켜려고 지금은 꺼 두었습니다.

여쭙고 싶은 것은 세 가지입니다.

1. 위 방식으로 제 근무 일정을 자동 조회하는 것에 동의해 주실 수 있을까요?
2. 동의가 어렵다면, 구성원이 본인 근무 일정을 개인 캘린더로 받아 볼 수 있는 공식 방법(개인용 캘린더 구독 주소 등)이 있거나 준비 중인지 궁금합니다.
3. 동의해 주신다면 요청 빈도나 방식에 지켜야 할 조건이 있는지 알려 주세요.

감사합니다.
